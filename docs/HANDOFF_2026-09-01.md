## 1. One blocked command — finishes the deploy

Traefik config is staged at `coolify:~/trading-agent.yaml`. Needs `sudo` (blocked for the
assistant, allowed for you):

```bash
ssh coolify 'sudo cp ~/trading-agent.yaml /data/coolify/proxy/dynamic/trading-agent.yaml \
  && sudo chown root:root /data/coolify/proxy/dynamic/trading-agent.yaml \
  && sleep 8 && curl -s -o /dev/null -w "https: %{http_code}\n" https://agent.mphinance.com/mcp'
```

Traefik watches that dir and requests the cert on first hit.
**Expect a 4xx.** An unauthenticated `/mcp` request must be rejected — a `200` means auth
isn't gating and something is wrong.

  that in-flight work or revert the `__init__.py` change.

  2.0.16, a fresh resolve gets 2.0.19. Pinned manually on coolify; the repo should pin it too.

  lands on vultr's Apache and returns a confusing 503 from the wrong machine.

  carve-out written as what it actually is: docker-bridge bind, Traefik-fronted,
  bearer-gated. Not dressed up as loopback.

  `recall_similar_setups()` auto-sync from `conviction.py:194` and `:319`, tested at
  `test_conviction_journal.py:348` — but were mentioned *only* in a ticked ROADMAP checkbox
  at line 383. Now documented in CLAUDE.md and exposed as an MCP tool.

  nodes, so `asyncio.to_thread(guard.place, …)` — the exact idiom the live order path

  shapes. Don't narrow it back.
